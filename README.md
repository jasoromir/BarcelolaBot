# BarcelolaBot

WhatsApp automation bot for a Barcelona tour agency. Broadcasts tour announcements to WhatsApp groups on a schedule, opens/closes groups at night and morning, and sends real-time booking confirmation DMs driven by Wix webhooks.

Active redesign. See [docs/superpowers/specs/](docs/superpowers/specs/) for the design document and [docs/superpowers/plans/](docs/superpowers/plans/) for the implementation plan.
